# Copilot Instructions

## Project Overview
The Model Editor project is designed to provide a user-friendly interface for editing and managing data models. It supports various data formats and provides tools for visualization and interaction with models.

## Key Technologies
- **Framework:** React
- **State Management:** Redux
- **API Client:** Axios
- **Testing Framework:** Jest
- **Styling:** CSS Modules
- **Build Tool:** Webpack

## Core Concepts
- **Models:** Structured representations of data, including attributes and relationships.
- **Languages:** Support for multiple languages for internationalization.
- **CRUD Operations:** Create, Read, Update, Delete functionalities for managing models.

## Development Guidelines
1. **Code Structure:**
   - Follow a modular approach for organizing components.
   - Use Redux for state management for complex components.
2. **Commit Messages:**
   - Use clear and concise messages describing the purpose of the commit.
   - Follow the format: `type(scope): subject` (e.g., `feat(model): add new validation`)
3. **Pull Requests:**
   - Ensure all changes are reviewed before merging.
   - Link related issues in the pull request description.

## Testing Approach
- Write unit tests for components and Redux logic.
- Use Jest for running tests and ensuring code quality.
- Ensure at least 80% test coverage for new features.

## Common Patterns for Working with Models
### Creating Models
- Use the provided API client to create new models. Ensure validation is performed before API calls.

### Reading Models
- Fetch models using GET requests and update the Redux store accordingly.

### Updating Models
- Implement form components for editing model attributes.
- Dispatch Redux actions to update the application state and make API calls.

### Deleting Models
- Use delete confirmation dialogs before making DELETE requests to ensure data integrity.
- Update the state to reflect the removal of the model immediately after deletion.

## Conclusion
These instructions aim to streamline the development process and enhance collaboration among team members. Implementing these guidelines will help maintain a high standard of code quality and project organization.
