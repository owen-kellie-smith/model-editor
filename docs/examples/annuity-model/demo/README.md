# Annuity Model run with actual data

The model-editor makes up input table content in order to render results.  You can use your own actual data
- in the exported spreadsheet by pasting over the tables generated by the model-editor
- alongside the exported Python script by storing .csv file named input_<table_name>.csv in the same folder as the .py script.

This directory contains hard-coded inputs suitable for the annuity model.
